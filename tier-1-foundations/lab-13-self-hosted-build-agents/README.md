**Tier:** Tier 1 - Foundations

## The Problem

Your build pipelines can no longer reach private resources because hosted agents run outside your network. Deploy self-hosted agents inside the virtual network, with autoscaling, no inbound ports, and no long-lived credentials on the agent machines. Ensure agents can pull tooling from approved sources only.
