## The Problem

Route all outbound traffic from a spoke through Azure Firewall in the hub. Workloads may reach a defined list of fully qualified domain names and nothing else. Everything denied must appear in the firewall logs with enough detail to identify the source workload. Show why a network rule and an application rule produce different log entries for the same request.
