## The Problem

Connect a simulated on-premises network to Azure and make private endpoint names resolve correctly from both sides. On-premises resolvers must conditionally forward Azure zones, and Azure workloads must resolve on-premises names. Do this without deploying any DNS forwarder virtual machines. Prove resolution in both directions.
